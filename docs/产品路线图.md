# BetterRAG 产品路线图 v2

> v2 按「机制五问」瘦身为 **5 项探索层 + 灵感存档**。探索层规则：**每项必须附核心退路**（探索机制坏了，系统退回核心照跑）。灵感存档：**不承诺、不排期、可取回**——仓库不替它们背维护责任。
> 已转正进核心的原路线图项：独立佐证（并入挑刺案卷）、影子双答（核心仲裁）、知识传记（demo 特性）、铁律修正案（核心规则三）。

## 探索层（demo 之后，每项附退路与五问待验）

| # | 方向 | 一句话 | 核心退路 |
|---|---|---|---|
| 1 | **影子降级（金丝雀）** | 稳定块降级前先试停用、观测结局疼不疼：承重墙保护，无感者坐实降级——降级从阈值触发升级为证据触发，系统性消灭误杀 | 阈值降级（核心现行为） |
| 2 | **矛盾巡检** | 夜间 embedding 近邻配对 + LLM 分型扫描，全库主动体检：互斥→仲裁预备、新替旧→取代预备、冗余→合并建议 | 行为级冲突检测（核心现行为） |
| 3 | **落地追问判定** | 用 LLM 识别「基于答案行动」的强正向证据（消费域信号增强：重问/转人工之外的可靠正信号） | 证据仅计工单回调与按钮信号 |
| 4 | **预定接替** | 政策提前发布场景：管理员导入时标注生效日与接替对象，到点自动执行修正案——修正决定一次做出，执行自动完成 | 手动一键接替（核心现行为） |
| 5 | **缺口空间探测** | 问题的 embedding 落点离所有稳定质量都很远 ＝ 知识缺口的几何判据；缺口驱动主动收纳（归档不拒问同源） | 无（纯增益，核心不受影响） |

## 灵感存档（一行一项，不承诺）

子块手术（负信号子句级聚集→切分降级）· 连坐审查（判错块的高共引邻居进预审）· 冲突四型分诊（粒度型成对呈现）· 判例仲裁（裁决沉淀先例库）· 影子陪审团（N 用户统计采样裁决）· 知识自梦（夜间自问自答提前发现内部矛盾）· 知识疫苗（判错样本回归测试集）· 知识混沌工程（隐藏块压测真实重要性）· 社区发现→变化速率域自动划分 · 时代切片问答（审计链 as-of 重放，合规举证）· 知识时间窗（生效日预激活）· 代谢校准（历史回放拟合半衰期参数）· 归档不拒问（归档高相似命中→缺口信号）· 信任分级订阅（用户侧信任偏好分层）· 审计链防篡改（签名/存证）· owner 责任制 · 用户声誉加权 · 低流量模式（阈值按流量校准）· 多租户与分布式一致性 · 热度证据差可视化（采纳量≫证据量的体检视图）· 供应商 fallback 链 · PDF/多模态解析
