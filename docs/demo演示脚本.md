# BetterRAG 黑客松演示脚本 v4（十镜三幕，约 12 分钟）

> 配套：[生命周期引擎规格 v4](./生命周期引擎规格.md)。结构：**三幕对应三条核心规则**——幕一·信号（知识怎么挣信任）→ 幕二·慢升（知识怎么转正）→ 幕三·免疫（知识怎么退场）。每镜一句话可复述；观众看完能复述就是「易懂」的验收。

## 演示前 30 分钟布置

| 项 | 内容 |
|---|---|
| 预置语料 | 15 篇资费 Markdown：8 篇管理员导入（稳定区，含背书；2 篇铁律：《计费稽核铁律》《入网合规规范》）、4 篇学习区、3 篇预备区 |
| 预置事件史 | 审计链预灌 INGEST/ADOPT/EVID 事件；星图预计算 |
| 镜 5 道具 | 《5G 新套餐政策》已收纳；重放脚本含 15 笔工单一次闭环证据 |
| 镜 6 道具 | 例外队列预置一条挑刺红旗条目（与稳定区旧资费块未决矛盾 + 重问聚集） |
| 镜 7 道具 | 《停售公告》预成长至 0.62（举证期） |
| 镜 7.5 道具 | 《政策方向调整》开场前已收纳，预置一次共现 |
| 备用 | FAQ 语料包、备用 key、全程录屏 |

## 第一幕 · 信号（知识怎么挣信任）

### 镜 1 · 开场：知识星图（1 分钟）

- **操作**：打开仪表盘星图。
- **屏幕**：分区着色星图（金=稳定、蓝=预备、绿=学习）、冲突连线、滚动事件流。
- **话术**：「企业知识库只有记忆，没有新陈代谢——错误知识入库就永久污染。这个库不一样：星图上每颗星是一条知识，颜色是它的信任身份，而这张图是活的。」
- **卖点**：星图 = 全部机制的视觉替身。

### 镜 2 · 冷启动（1 分钟）

- **操作**：引擎接入页填地址/key/模型 → 测试连通；展示管理员导入。
- **话术**：「私有化部署，接你们自己的模型；存量知识管理员导入直进稳定区——企业第一天就能用。」
- **卖点**：自接引擎 + 管理员导入 + 铁律设置。

### 镜 3 · 收纳：只照搬（1.5 分钟）

- **操作**：把《5G 新套餐政策》（Markdown）拖入工作区，点「立即扫描」。
- **屏幕**：INGEST 事件、归纳摘要标签、块入学习区 0.30。
- **话术**：「Agent 自己学新材料。入库的全是**原文切片**，AI 只贴标签不改内容——幻觉进不了门。」
- **卖点**：工作区 + 照搬原则（ADR-0003）。

### 镜 4 · 问答与证据（1.5 分钟）

- **操作**：问「现在有什么优惠套餐？」→ 答案引用学习区新政策（标注「新知识」）→ 点 👍。
- **话术**：「新知识当天可用，但必须亮明身份。注意积分规则：答案用到它只是入场券，用户之后的真实行为才是证据——工单一次闭环 +0.02，重问 −0.02，**沉默不计分**。演示里这个 👍 代表工单闭环：真实系统由工单回调自动供证，用户零动作。」
- **卖点**：信号分桶（活性/证据/沉默）+ 惰性公理。

## 第二幕 · 慢升（知识怎么转正）

### 镜 5 · 举证期与自动转正（1.5 分钟）

- **操作**：⏩ 快进 90 天（重放 15 笔闭环证据）→ 新政策块跨 0.60 入举证期 → 再快进 7 天 → AI 挑刺 → 自动转正。
- **屏幕**：星图绿点先冻结（举证期）再变金；审计链出现 AUTO_PROMOTE（附案卷）。
- **话术**：「证据攒够，系统自己开庭：七天举证期，AI 挑刺——查矛盾、查佐证、查疑点。挑不出毛病，**自动转正**。从试用期到骨干，没有任何人点过按钮。」
- **卖点**：自证晋升（ADR-0005）。

### 镜 6 · 例外裁决（1 分钟）

- **操作**：打开例外队列（只有一条）→ 看挑刺案卷（与稳定区旧资费块未决矛盾、重问聚集）→ 点「拒绝」。
- **屏幕**：条目置 0.30 积分清零回学习区；审计链记录裁决。
- **话术**：「机器不敢担保的才轮到人。今天例外队列只有这一条——这就是管理员的全部工作量：半小时一周，只裁疑难。」
- **卖点**：人工负载 ∝ 例外量（不是流量）。

## 第三幕 · 免疫（知识怎么退场）

### 镜 7 · 影子对决（2 分钟，全场高潮）

- **操作**：问一个新旧政策都命中的问题 → 冲突计数 +1 → 再问两次 → N=3 → 仲裁阶梯。（《停售公告》预成长至 0.62——没攒够证据的知识，连影子对决的资格都没有。）
- **屏幕**：置信度差 0.85−0.62=0.23 < 0.25 → 影子双答并排（旧政策块上下文 vs 新公告块上下文）。
- **操作**：请评委当场点选 → 点新 → 旧块置 0.70 落待处置，挑战者 +0.10。
- **话术**：「稳定区不会被劣币驱逐——先对冲，分不出胜负就打影子对决。你们刚才点的那一下，就是业务结果闭环。」
- **卖点**：冲突检测 → 仲裁阶梯。

### 镜 7.5 · 铁律红灯（45 秒）

- **操作**：问一个新旧方向都命中的问题 → 共现触发 → 铁律异议 +1、挑战者挂起保全 → 红灯横幅亮起 → 打开修正案视图（新旧并排+证据）→ 一键接替。
- **屏幕**：《计费稽核铁律》异议计数、《政策方向调整》挂起保全、红灯置顶；接替后星图金点迁移，旧铁律归档留取代链。
- **话术**：「铁律不会被算法废黜——宪法只能由人修。但被现实挑战时整栋楼亮红灯：挑战者被保全、异议在计数、负结局在记账。管理员一键接替，取代链留档，合规可查。」
- **卖点**：铁律记账零豁免 + 修正案。

### 镜 8 · 衰减归档（1 分钟）

- **操作**：⏩ 快进 400 天（重放：主流资费持续保鲜，旧套餐块无人问津）。
- **屏幕**：旧块滑回学习区 → 跌破 0.05 → 自动归档；降级报告（「已 357 天无有效证据」「仲裁败诉」）+《旧政策的一生》薄版传记。
- **话术**：「知识有保鲜期：沉默不算满意，但沉默会让它过期。稳定区半衰期一年，学习区 232 天证明窗口——不删除，归档留案底，人工可翻案。」

### 镜 9 · 时间滑块与迁移（0.5 分钟）

- **操作**：星图拖时间滑块回放全程；一键切换 FAQ 语料。
- **话术**：「拖动滑块，看这个库三个月的代谢史。换份语料 30 秒——新陈代谢是任何 RAG 的普遍能力。」

### 镜 10 · 金句（0.5 分钟）

「我们不造更强的模型，我们给知识库装免疫系统：被动结局供证、慢升快降、当场仲裁、宪法可修。创新在原则层，不在机制数量层。**越用越准，越用越干净。**」

## 事故预案

| 事故 | 预案 |
|---|---|
| API 不通 | 引擎接入页手动填备用供应商（现场演示自接引擎，反而加分）；终极兜底放录屏 |
| 收纳超时 | 用预置学习区材料顶替镜 3，叙事不变 |
| 评委不点选（镜 7） | 自动超时 → 计数 −1 渐忘机制，顺势讲「仲裁不强制，冲突会渐忘」 |
| 快进后无变化 | 检查重放脚本已应用、协调 tick 已跑 |
| 红灯场景失灵（镜 7.5） | 口述修正案机制并展示预置截图 |

## 时间账

1+1+1.5+1.5+1.5+1+2+0.75+1+0.5+0.5 ≈ **12.25 分钟**。限时 8 分钟方案：镜 2/9 合并口述、镜 7.5 口述并展示截图、镜 3 等待时讲镜 4 → ≈8.5 分钟。**镜 5 与镜 7 不可压**（核心机制）。
