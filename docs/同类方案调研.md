# 同类方案调研：知识生命周期的先例地图

> **调研方式**：两个后台研究员并行跑学术线与产品线，全部一手来源（arXiv 论文原文、官方文档、GitHub 仓库），查不到的明确标注，未编造任何功能。本文件是两条线的合并结论与话术建议；产品线逐项证据见 [竞品调研-知识生命周期先例.md](./竞品调研-知识生命周期先例.md)。
>
> **对照基准**——BetterRAG 四件套：(a) 用户使用信号驱动的自动晋升计分；(b) 时间衰减驱动的自动降级（无人参与）；(c) 新旧知识冲突的仲裁机制（对冲/影子 A/B）；(d) 进入高信任层的人工审核关卡。

---

## TL;DR

1. **思路灵感.md 对比表引用的两个项目（Contemplative Agent、ai-wiki）均查证属实**，对比句可以放心说。
2. **没有任何已知系统同时具备四件套**。三个最近邻：ARIADNE（学术规范，2026-02，缺 a）、Guru（商业，覆盖广但全是"AI 提议人决断"）、unimatrix（开源设计，自己推翻了纯时间衰减）。
3. **我们最大的差异是"执行权"**：所有先例都是"信号采集 → AI 提议 → 人决断"，BetterRAG 是"信号 → 自动执行升降级，人只守一道门"。
4. **一处必须修正的宣称**：「阈值晋升 + 时间衰减 + 人工审核门」这套**骨架**已有先例（ARIADNE、Guru 自动归档），不能说骨架首创。
5. **一条实战教训必须吸收**：unimatrix 实测纯时间半衰期会误伤"低频引用×高价值"知识——我们的衰减已挂使用信号，方向正确，但 demo 必须包含此风险案例。
6. **一个意外的市场弹药**：Guru 2026 年把新集合默认验证改为"永不过期"——人工验证疲劳的真实证词，直接引出"让信号自动执行"的必要性。

## 一、查证结果：思路灵感.md 的对比表是安全的

| 被引用项目 | 查证 | 机制实情 | 对比句是否成立 |
|---|---|---|---|
| **Contemplative Agent**（[GitHub](https://github.com/shimo4228/contemplative-agent)，Zenodo DOI 10.5281/zenodo.22724623） | 真实存在，个人研究项目 | episode log（不可变原始）→ pattern store → agent 提议晋升 value layer，每次晋升过人工批准门（其 ADR-0012）；无任何衰减降级机制 | ✅「只有单向晋升，没有降级」属实 |
| **ai-wiki**（[GitHub](https://github.com/tim-kaa-py/ai-wiki)） | 真实存在 | sources/ 原文逐字不可变 → summaries → wiki；CONNECT 步骤检测矛盾后**逐字引用双方 claim 浮现给人工决定**（accept/keep/hold/synthesize/defer），悬置矛盾进 append-only 台账 | ✅「冲突仅提示，不触发降级」属实 |

两个项目都撞在我们的"照搬原则"上：它们同样坚持原文 verbatim、AI 只做摘要——说明这条路线是行业共识，不是我们的一厢情愿。

## 三、三个最近邻深潜

### 3.1 ARIADNE——骨架先例，必须诚实承认

[Zenodo 18507994](https://zenodo.org/records/18507994)（2026-02-06，罗马尼亚奥拉迪亚大学，DAEDALUS 项目的 Neo4j 工作记忆规范；非同行评审，下载量 66，经父代理二次核验记录真实）。

**机制**：三层记忆图；三因子检索（recency×importance×relevance，指数衰减）；夜间"sleep"巩固（冲突检测 + 未强化事实置信衰减）；**Fact Promotion 管线：confidence >0.95 自动晋升入 ATHENA（human-approved 策展层），0.85–0.95 批量审，<0.85 人工审**。设计原则原文："ARIADNE remembers everything, trusts nothing / ATHENA trusts everything here"。

- **与我们的重叠**：衰减（#3）、分级审核门（#4）、三因子检索。
- **它没有**：用户引用积分（confidence 不由真实用户反馈产生）、影子 A/B、铁律、来源标注。
- **有趣细节**：它的规范自己把 "Overconfident Auto-Promotion" 列为 Anti-Pattern 2，却仍允许 >0.95 自动晋升——我们 ADR-0001 的机器写入上限（自动事件不得跨越稳定区下界）从结构上杜绝了它自我警告的病。
- **话术影响**：不要宣称"阈值晋升＋衰减＋人工门"骨架首创；ARIADNE 知名度极低，路演不必点名，但内部记录在案。

### 3.2 Guru——商业最近邻，且是市场验证

官方文档三件套：人工验证（验证人＋间隔 30/60/90 天/半年/年/永不过期）→ 自动归档（"未验证满 6 个月＋零浏览"→ 待归档队列 → 一周无人处理自动归档，**归档卡不进搜索与 AI 答案**）→ 2026 新功能 Automated Knowledge Quality（AI 用使用信号＋内容信号持续自动验证/撤销，每次给理由＋confidence level＋全量审计日志，人可否决）。

- **它没有**：段落级连续置信度、引用计数→自动晋升冻结、答案级信任标注、冲突仲裁。
- **关键市场信号**：**2026 年起新集合默认"永不过期"**——企业受不了周期性人工验证（验证疲劳），Guru 先软化默认值、再用 AI 自动化补回来。这就是 BetterRAG"让信号自动执行、人只守一道门"的需求侧论据。
- **差异本质（执行权）**：Guru 官方定位是 "Automation proposes verification… experts retain full visibility and control to review, override"——全部 AI 提议、人决断。BetterRAG 让信号自动执行升降级，人只守稳定区一道门＋抽查否决。

### 3.3 unimatrix——最珍贵的实战教训

开源设计文档（[issue #363](https://github.com/dug-21/unimatrix/issues/363)）：曾用 7 天半衰期纯时间衰减 → **项目静默期全库等速衰减、旧而有效的参考知识被误伤** → 亲手推翻，改为"时间只作 TTL 门控、不作健康信号"，新鲜度=注入率（被使用）。

- **对我们的意义**：BetterRAG 的衰减本来就挂使用信号（闲置天数自上次正向信号起算、宽限 14 天、引用/点赞重置保鲜）——方向与 unimatrix 的最终结论一致。但必须验证"低频引用≠低价值"场景（如运营商基础资费，很少被引用但长期有效）：
  - 现有缓解：稳定区 365 天长半衰期、tenure 攀升延长闲置容忍（80→165 天）、铁律豁免。
  - **行动项**：demo 语料放一条"低引用×高价值"条目，演示它不因冷清被误杀；产品阶段可做"纯时间衰减 vs TTL 门控"对照实验。

## 四、原创性判定：真正没人做过的三件事＋一个赌注

1. **执行权自动化**（最大差异）：真实用户问答产生的积分（采纳＋0.02/赞＋0.03/踩−0.04）自动驱动晋升与降级，人只守一道门。所有先例要么"信号采集→AI 提议→人决断"（Guru、Sierra、Dify、unimatrix 降级受限），要么"信号只影响排序不改状态"（Generative Agents）。
2. **完整仲裁阶梯**：铁律恒胜 → 置信度差 ≥0.25 对冲判负 → 影子 A/B 并排双答用户当场点选。三级阶梯无先例——Graphiti/Mem0/ARIADNE 全是单一规则裁决；Bloomfire 有检测＋并排对比但只辅助人工，没有"让用户当场裁决并把结果写回置信度"的闭环。
3. **单一连续状态变量闭环**：衰减、积分、分区全部作用在同一置信度标量上（分区=区间投影，物理无 zone 列）。ARIADNE 等均以多字段/多机制分散实现。
4. **（待验证的赌注）先上线后审＋答案级信任标注**：商业产品全部先审后发（Sierra 原文 "approved before publication"），答案级信任标注未见先例（最接近=Guru 卡片级 trust indicator）。这是可主张的差异，但"标注来源：学习区"是双刃剑——可能成为诚实卖点，也可能被读成免责声明，需要实测。

## 五、思想谱系（我们站在谁的肩膀上）

| BetterRAG 概念 | 先例 | 用法 |
|---|---|---|
| 时间衰减（freshness 指数衰减） | MemoryBank 遗忘曲线（[arXiv 2305.10250](https://arxiv.org/abs/2305.10250)）；Generative Agents recency 0.995/小时（[arXiv 2304.03442](https://arxiv.org/abs/2304.03442) §4.1） | 分享文档提一句"记忆系统的遗忘曲线" |
| 三因子检索（相关性×置信度×新鲜度） | Generative Agents：recency×importance×relevance | 同构致敬 |
| 分级治理＋人工评审＋降级 | Wikipedia 巡查制、GA/FA reassessment 除名 | 路演讲"维基百科早已证明分级治理可行，但它是纯人工" |
| 知识成熟度连续体 | EU MATURE Knowledge Maturing Model（2008–2012，[CORDIS](https://cordis.europa.eu/project/id/216356)） | 内部文档正名 |
| 失效不删除 | Zep/Graphiti："old facts are invalidated — not deleted"（[GitHub](https://github.com/getzep/graphiti)） | 我们归档可审计的同源 |
| 新鲜度调权 | Google QDF（[2009 官方博客](https://developers.google.cn/search/blog/2009/10/suchanfragen-verdienen-aktualitaet)、[2011](https://search.googleblog.com/2011/11/giving-you-fresher-more-recent-search.html)） | "搜索引擎早就在按查询类型调新鲜度权重" |
| 外置知识库路线 | NeurIPS 2024：连续数十次知识编辑即毁模型通用能力（[arXiv 2410.18785](https://arxiv.org/abs/2410.18785)） | **弹药**：改参数不可持续，外置＋治理才是路线 |
| 按知识变化速率定半衰期 | FreshQA（[arXiv 2310.03214](https://arxiv.org/abs/2310.03214)） | **弹药**：所有模型在 fast-changing 知识上表现差 |

## 六、话术修正清单（分享介绍 / 路演）

**可以放心说的（已查证）**：
- ✅「Contemplative Agent 只有单向晋升没有降级」
- ✅「ai-wiki 冲突仅提示不降级」
- ✅「商业 AI 客服平台全部先审后发，新知识要等人工」
- ✅「没有已知系统同时做到四件事」（措辞用"没有已知"，不用"全球首创"）

**必须软化/修正的**：
- ❌ 不说「阈值晋升＋时间衰减＋人工审核门」骨架首创——ARIADNE（2026-02）、Guru 自动归档已有骨架。
- ❌ 不说「没有产品用使用信号驱动知识质量」——Guru Automated Knowledge Quality、Sierra 引用频次都在用。**正确说法：「信号到处都在采集，但没有人让信号自动执行升降级——全部是 AI 提议、人决断；我们让信号自动执行，人只守一道门。」**

**建议新增的弹药**：
- Guru 2026 新集合默认"永不过期"→ 人工验证疲劳的市场证词。
- NeurIPS 2024 连续编辑毁模型 → 外置知识库路线背书。
- FreshQA → 分级半衰期的学术支撑。

**对比表可加的两行**（进分享介绍第三节）：

| 方案 | 缺的那块 | BetterRAG 补上了 |
|---|---|---|
| Guru（企业 KM 自动验证） | 信号只做提议、人决断，粒度卡片级 | 信号自动执行升降级，段落级置信度，人只守一道门 |
| Agent 记忆系统（MemGPT/MemoryBank） | 记忆只影响排序不淘汰，或衰减单向无仲裁 | 双向闭环＋冲突仲裁阶梯＋人工门 |

## 七、可借鉴清单（升级设计的输入）

1. **ARIADNE**：0.85–0.95 批量审缓冲档——审核台加"批量通过"档位，低成本。
2. **Guru**：归档前一周缓冲窗——自动归档前给管理员一次否决机会。
3. **Guru**："编辑即恢复可信"——我们的对应物是"人工事件重置保鲜"，确认两者语义一致后写进规格注记。
4. **ai-wiki**：append-only 矛盾台账——conflicts 表已是 append-only，展示层做成台账视图。
5. **MemoryBank**：衰减＋强化双通道——我们已具备（衰减单向；正向信号双效：加分＋重置保鲜），在规格里明确命名。
6. **Sierra**：转人工对话＝知识缺口信号源——产品阶段工作区之外的第二收纳触发器。
7. **Dify**：标注命中频次追踪——引用计分采集件的同构参考。
8. **Microsoft Purview**：多阶段处置＋超时自动批准窗口——归档流程的合规级参考。

## 八、风险与待验证

1. **纯时间衰减误伤**（unimatrix 教训）：衰减挂使用信号＋宽限期＋稳定区长半衰期＋tenure＋铁律，方向正确；demo 必须含"低引用×高价值"案例。
2. **来源标注 UX 风险**：诚实卖点 vs 免责声明，一线之间；demo 收集现场反应，必要时做标注 A/B。
3. **ARIADNE 演进**：2026-02 刚发布，进竞品雷达，保持关注。
4. **中文生态空白＝机会窗口**：智齿/七鱼/百度客悦/追一/KAG/Coze 普遍"录入-解析-检索-人工维护"，未见使用信号驱动的信任分级——国内市场差异化更鲜明；落产品时审计链恰好是国内合规刚需，正中我们的强项。
