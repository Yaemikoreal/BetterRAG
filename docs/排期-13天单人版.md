# 排期：13 天单人特供版（2026-09-29 定档）

> 输入事实：**1 人全职 × 13 个工作日**（从 D1 起算），网络与 LLM API 无忧。
> 判定：三档预估（完整 24.5 / 精简 21 / 保底 17 人日）**全部超预算**——本排期以「范围再裁 + 估算压缩」达成 **12.5 人日（含排练）+ 0.5 缓冲**。90% 置信度排期，触发线即保险。

---

## 0. 永不砍的四件

**影子对决（缓存制）、⏩ 快进、来源透明、排练/录屏日。** demo 的灵魂在这四件，其余皆可让。

## 1. 范围表

**做（13 天版 IN，v4 口径）**：
- 引擎全机制：收纳（md/txt）、证据分桶（采纳=活性/结局=证据/沉默零计分）、幂等去重、举证期（7 天冻结）、AI 挑刺与自证晋升、例外裁决、衰减协调、自动降级、归档、铁律（红灯+修正案）、冲突计数、仲裁阶梯、影子（缓存制）、来源透明、探索召回
- UI：单页三 tab（问答 / 例外裁决台 / 仪表盘）+ 引擎接入配置表单 + ⏩快进 + **知识星图**（分区着色+冲突连线+时间滑块）+ 红灯横幅 + 事件流 + 降级原因报告 + 薄版传记
- 语料：15 篇资费 Markdown（8 管理员导入含 2 铁律 / 4 学习区 / 3 预备区）+ 挑战者预成长（0.62）+ FAQ 备用包
- D13 彩排 ×2 + 录屏 + runbook + 事故预案卡

**不做（口述弹药，归 [产品路线图.md](./产品路线图.md)）**：
E1 k 来源独立佐证（幂等去重保留）、晋升存活率、矛盾台账视图、谱系树视图（superseded_by 字段保留）、摘要检索初筛通道、影子运行时双生成、供应商 fallback 链、PDF/多模态、时代切片/融合判决/联名块（stretch 全灭）。
→ 评委问起的标准答法：「已设计、已归档路线图，demo 按时序呈现核心闭环。」

## 4. 触发线（单人纪律：当天砍，不过夜）

- M1 晚于 D3 收工 → 砍 探索召回 + D1 传记（−0.5）
- M3 晚于 D9 上午 → UI 降一页版（问答+队列合体；仪表盘只留分区条+快进；−1.0）
- M4 晚于 D12 中午 → 砍 FAQ 彩蛋，保 录屏
- 最坏预案：M3 仍不达 → 预置状态快照 + 引擎单测输出作为机制证据（demo 弱化但成立）

## 5. 单人纪律

- 每日收尾三行日志：明天第一件事 / 今天卡点 / 新发现——单人时日志就是队友；
- 对规格的任何偏离当天记注记，不靠记忆；
- LLM 调用只经 llm.py 角色映射——换模型只动一处；
- 触发线触发就砍：**犹豫是单人项目最大的时间黑洞**。
