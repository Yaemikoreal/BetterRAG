## 30 秒版

企业知识库全靠人维护，而人有惰性——于是知识只进不出，越攒越烂。BetterRAG 是第一个**自己维护自己**的知识库：每条知识的信任由**真实使用的结局**供证（工单一次闭环、重问、转人工——用户零动作），**慢升快降**（举证期自动转正、衰减自动退场），冲突当场仲裁，铁律自带修正程序。**越用越准，越用越干净。**

## 一、痛点：知识库死于人的惰性

一个真实场景：某运营商上了 AI 客服，半年后套餐停售、新资费出台——客服 Agent 还在用旧政策回答每一个新用户。投诉、合规风险，而没人知道库里躺着一篇早该下线的文档。

为什么所有现有方案都失败？因为它们全部假设**人勤快**：Guru 要求专家定期验证（验证疲劳到官方把新集合默认改成「永不过期」——这是市场投降书）；人工审核会积压；定期清理没人做。

**人就是懒——这句批评，是我们的第一公理。** BetterRAG 的全部燃料来自用户本来就会做的事（问问题），全部维护来自自动代谢，人只裁例外。

## 二、核心：一个变量、两种信号、三条规则、一张图

**一个变量**：每条知识（精确到段落级「知识块」）有一个置信度分数，三个分区只是分数的区间——**学习区**（试用期）、**预备区**（举证期）、**稳定区**（骨干，其中法规章程挂「铁律」位）。

**两种信号**：答案用到某知识块＝**采纳**，只保鲜不加分；用户之后的真实结局才是**证据**——工单一次闭环 / 落地型追问 +0.02，重问 −0.02，转人工 −0.03，点赞是弱正，**沉默计零**（满意、放弃、离开长得一样，我们不给未知打分）。全部被动：用户零新增动作。

**三条规则**：

1. **慢升**：证据攒过线 → 七天举证期 → AI 挑刺（查矛盾、查佐证、查疑点）→ 通过**自动转正**，不通过交人。从试用期到骨干，没人点过按钮。
2. **快降**：负证据加衰减，破线自动降级、过期自动归档——不删除、留案底、可翻案。
3. **铁律特例**：法规章程不自动降级、冲突必胜——但**记账零豁免**：被现实挑战会亮红灯，管理员一键接替（修正案+取代链）。宪法不被算法废黜，但宪法自带修正程序。

**一张图**：知识星图——分区着色、冲突连线、时间滑块。不用听机制清单，看一张会代谢的图。

## 三、跟随一条知识的一生

《5G 新套餐政策》入库（**原文照搬**，AI 只贴标签，幻觉进不了门）→ 当天参与问答（亮牌「新知识」）→ 15 笔工单一次闭环 → 举证期七天、AI 挑刺通过 → **自动转正** → 三个月后《停售公告》入库、冲突计数、**影子对决**（新旧并排，用户当场点选，旧政策降级）→ 又过一年无人问津，跌破废弃线自动归档，留下降级报告和《旧政策的一生》传记。全程审计链，随时回放。

## 四、创新定位（诚实版）

| 方案 | 缺的那块 | BetterRAG |
|---|---|---|
| Guru（企业 KM 自动验证） | 信号只做提议、人决断一切 | **机器自证晋升，人只裁例外**；证据由结局供证 |
| Agent 记忆系统（MemGPT/MemoryBank） | 记忆只影响排序、衰减单向无仲裁 | 双向闭环 + 影子对决 + 宪法修正程序 |
| 传统 RAG | 知识不分信任、永不退场 | 置信分区 + 自动代谢 |
| 知识图谱 / Graph RAG | 无使用价值度量 | 结局供证的置信度 |

原创性经 20+ 系统双线调研核验：「结局供证的自动晋升 + 完整仲裁阶梯 + 慢升快降」没有已知系统集齐；骨架（置信阈值 + 衰减 + 审核门）有先例，**我们不宣称首创——差异在原则层：让信号自动执行，让沉默过期，让宪法可修。**

## 五、五要素宪法与诚实边界

全部机制先过五问才进核心：**一句话讲清吗？成本声明了吗？坏了有退路吗？可测可演吗？差异清晰吗？** 因此核心只有七件：置信度、信号分桶、自证晋升、快降、铁律修正案、探索召回、星图。其余二十个创意（判例仲裁、时代切片、混沌工程……）在灵感存档里睡觉——**机制越少，原则越亮。**

诚实的边界：对连用户都察觉不到的错误，使用信号天然失明——我们的保证是**错误很难转正、转正了留案底、真知识一到就翻案**；消费域晋升天生慢（保守是设计不是缺陷）；demo 用 👍 代表工单闭环（产品接工单回调，零用户动作）。

## 六、落地：不是 PPT

13 天单人排期已定（第 4 天引擎骨架可在终端演示，第 13 天彩排录屏），技术形态刻意轻：SQLite 单文件 + 任意 OpenAI 兼容供应商（自接引擎）+ 换语料 30 秒。设计、调研、评估、排期文档全部开放——这套系统连自己都要求审计链，何况进度。
