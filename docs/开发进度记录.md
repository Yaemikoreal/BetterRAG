## 二、 核心源码资产与设计实现全景清单

项目核心工程代码规范落盘在 `src/` 目录下，彻底实现零外部重型服务依赖（免 Elasticsearch/Milvus/Redis/Celery）：

### 2.1 底层存储与治理内核 (`src/engine/`)
1. **[`src/engine/config.py`](file:///E:/myproject/BetterRAG/src/engine/config.py)**：置信度区间参数、tenure 宽限期、三段式降级锚定值与规整切片上下界（50~600字符）；
2. **[`src/engine/models.py`](file:///E:/myproject/BetterRAG/src/engine/models.py)**：Material、Block、AuditEvent、Citation、ConflictRecord 数据实体，严格解耦 verdict 与 status；
3. **[`src/engine/storage.py`](file:///E:/myproject/BetterRAG/src/engine/storage.py)**：SQLite WAL 模式、6 项性能索引、sqlite-vec 扩展与 jieba FTS5 虚拟表，`events.block_id` 免物理外键约束杜绝悬空炸弹；
4. **[`src/engine/confidence.py`](file:///E:/myproject/BetterRAG/src/engine/confidence.py)**：单变量置信度两分量纯函数数学，支持常青（`is_evergreen`）、举证冻结（`is_frozen`）、铁律免衰减，以及老知识 tenure 动态延长（80~165天）；
5. **[`src/engine/reconcile.py`](file:///E:/myproject/BetterRAG/src/engine/reconcile.py)**：每日衰减批处理，完整三段式降级（0.749 待处置 $\rightarrow$ 0.599 学习区 $\rightarrow$ 0.05 归档）与子块级联挂起保全；
6. **[`src/engine/ingest.py`](file:///E:/myproject/BetterRAG/src/engine/ingest.py)**：Markdown AST 语义段落树分块、防吞并条件子条款识别、一对多父子精准绑定、official/ 0.85 冷启动直进、增量 Hash 防漂移稳定继承；
7. **[`src/engine/arbitrate.py`](file:///E:/myproject/BetterRAG/src/engine/arbitrate.py)**：全量判决缓存（Hash 校验、兼容零 LLM 复用、冲突计数累加）与制度修正案一键原子接替；

### 2.2 检索、接口与信用闭环
8. **[`src/engine/retrieve.py`](file:///E:/myproject/BetterRAG/src/engine/retrieve.py)**：稠密向量 + BM25 融合打分、有效置信度动态加权过滤、探索召回保全席位（打破冷启动零曝光死锁）、父子语义上下文捆绑组装、来源置信度透明标牌生成；
9. **[`src/engine/credit.py`](file:///E:/myproject/BetterRAG/src/engine/credit.py)**：三轨信号源归因闭环、显著性 80%/20% 分摊、机器写入上限 0.749 保护、稳定区累加 tenure 宽限期、FastEmbed 语义向量余弦 60s 隐式同题重问检测；
10. **[`src/api/routes_chat.py`](file:///E:/myproject/BetterRAG/src/api/routes_chat.py)**：OpenAI 兼容 `POST /v1/chat/completions`（JSON 与 SSE 流式输出）、来源置信度标牌自动注入、显式反馈 `POST /api/v1/feedback`、系统同步与健康检查端点；

### 2.3 冲突流水线、沙箱挑刺与自治看板
11. **[`src/engine/probation.py`](file:///E:/myproject/BetterRAG/src/engine/probation.py)**：7 天举证观察期状态机（`is_frozen` 保护）、防提示词注入沙箱 AI 挑刺（`<untrusted_text>` 安全防护、权威基石召回比对、自动晋升 `AUTO_PROMOTE`）、待审例外人工裁决；
12. **[`src/engine/conflict_pipe.py`](file:///E:/myproject/BetterRAG/src/engine/conflict_pipe.py)**：两级冲突检测流水线（Pipe-1 摄取期静态互斥筛查、Pipe-2 检索期动态对冲检测与 `clash_count` 累加、红灯阈值告警）；
13. **[`src/api/routes_admin.py`](file:///E:/myproject/BetterRAG/src/api/routes_admin.py)**：例外待办列表与裁决端点、冲突台账端点、制度修正案一键接替端点、飞书卡片交互回调端点与看板指标端点；
14. **[`src/api/webhook.py`](file:///E:/myproject/BetterRAG/src/api/webhook.py)**：飞书富文本互动卡片构造（红灯预警、新旧规排版对比、一键接替/驳回按钮）与异步发送器；
15. **[`src/web/index.html`](file:///E:/myproject/BetterRAG/src/web/index.html)**：基于 Pico.css 构建的极简响应式治理看板，集成实时指标分布、制度冲突台账一键接替与异常待办人工裁决；
16. **[`src/main.py`](file:///E:/myproject/BetterRAG/src/main.py)**：FastAPI 服务生产入口、挂载全量路由与 `/dashboard` 看板视图、集成 APScheduler 定时执行衰减与举证审查。

## 四、 生产部署与运行实操 Runbook

### 4.1 本地直接启动
```bash
# 1. 复制环境变量配置文件
copy .env.example .env

# 2. 运行全量测试验证环境健全
py -3.11 -m pytest tests/ -v

# 3. 启动生产 API 服务与治理看板
py -3.11 -m uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload

# 4. 访问治理控制台
# 浏览器打开: http://localhost:8000/dashboard
```

### 4.2 Docker 单机一键交付部署
```bash
# 构建并启动独立容器
docker compose up -d --build

# 查看运行日志与健康状态
docker compose logs -f
curl -f http://localhost:8000/api/v1/health
```
