# 所有时间读数经过注入的虚拟时钟

引擎所有时间相关计算（freshness 衰减、协调任务、闲置天数）读注入的 `clock.now()`，仪表盘提供「⏩ 快进 N 天」按钮；真实参数（90/365 天半衰期）不为演示缩短。事件时间戳记虚拟时间，审计链显示「虚拟第 N 天」。

## Considered Options

- **现场等待真实衰减**：不可行——评委等不了 232 天。
- **把 demo 参数调成分钟级**：被否——演示完没人信这是真实尺度，方案可信度归零。
- **虚拟时钟注入**（本决策）：快进成为路演互动亮点，同时是可测试性的标准姿势（衰减单测无需 sleep）。

## Consequences

- 衰减必须实现为读时公式 + 幂等物化任务，时间跳变后全表重算一次即可。
- 快进按钮由 API `POST /api/clock/jump` 承载，产品化后同一机制即"时光机审计回放"。
