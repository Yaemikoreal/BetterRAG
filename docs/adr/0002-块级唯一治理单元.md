# 知识块是唯一的治理单元，材料状态全部由块状态汇总派生

一切治理动作（计分、晋升、降级、废弃、仲裁）作用于材料内的段落级知识块；材料没有独立的生命周期，其"归档"是全部块废弃后的派生状态。唯一例外是「整篇重审」——管理员把材料全部块打回预备区的逃生门，因为纯块级治理处理一篇烂文档要点 50 次降级。分区实现为置信度的读时投影，绝不做物理分 collection：治理单元是知识块，但召回单元是材料，跨区取相邻块上下文不能每次跨库。

## Consequences

- 同一材料 90% 在稳定区、10% 在学习区是正常态——"部分失效只降级失效段落"正是块级治理的兑现时刻。
- 归纳摘要挂在材料级（AI 标签），但答案的证据链只引用原文块。
