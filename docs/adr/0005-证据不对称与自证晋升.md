# 证据不对称：慢升快降与自证晋升

选题会压测与三轮追问确立了信号认识论的不对称：负向结局可靠（重问、转人工有方向），正向沉默不可靠（满意、放弃、离开不可分），而依赖主动反馈的系统会被人的惰性饿死。我们因此决定：信号分两层——**采纳只算活性**（重置保鲜时钟、不积分），**证据才计分**（正 +0.02、负 −0.02～−0.04，沉默为零）；**晋升由证据驱动且默认自证**（举证期冻结七天、一次 AI 挑刺，过则自动转正、不过交例外队列）；**降级全自动**（负证据 + 衰减，人不参与）。

## Considered Options

- **采纳即计分**（v3 旧案）：把沉默当正反馈，等于给未知打分——被否。
- **人工门保留为唯一稳定区入口**（ADR-0001 原案）：人工负载随晋升流量线性增长，是缩小版的 Guru 验证跑步机——被否。
- **证据双轨 + 自证晋升**（本决策）：人工负载 ∝ 例外量而非流量；合规域保留 `promotion.policy` 拨盘可切回人工门。

## Consequences

- 修订 ADR-0001 的一处条款：`AUTO_PROMOTE` 成为稳定区第二入口（唯一有权跨越稳定区下界的机器事件，事件附完整案卷）；常规积分事件的 0.749 上限不变。
- 消费域晋升天生慢（保守即设计）；客服域由工单一次闭环量产证据。
- 防错误晋升由多层机器过滤承担（负证据 → 沉默过期 → 挑刺 → 冲突 → 晋升后终身监控），人工只审认识论残余与例外。
