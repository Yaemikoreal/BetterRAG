# 置信度是唯一的状态变量，三级分区是它的区间投影

三级分区曾被当作三个独立实体（各自的存储、各自的迁移操作）。我们决定反其道：系统只有一个连续状态变量——置信度；分区 = f(置信度) 的区间投影；晋升、降级、仲裁、审核全部建模为带审计的置信度增量事件；检索权重直接取有效置信度数值。机器事件不能把非稳定区块写入稳定区间（跨入上限 0.749，即稳定区下界之下）；稳定区只能由人工事件（审核、管理员导入）开启，开启后机器积分允许区内攀升。（注：加粗条款已由 [ADR-0005](./0005-证据不对称与自证晋升.md) 修订——`AUTO_PROMOTE` 成为稳定区第二入口，唯一有权跨越下界的机器事件；常规积分事件的 0.749 上限不变。）

## Considered Options

- **分区独立状态机**：每区各自存储、迁移是显式 move 操作。被否——存储和迁移成本翻三倍，且"分区"与"置信度"两个数值可能分叉。
- **双变量模型**（分区状态 + 独立置信度）：被否——两个变量必然漂移出不一致状态，调试噩梦。
- **单变量区间投影**（本决策）：物理上不需要三个 collection，全生命周期审计 = 单变量的变化史。

## Consequences

- "分区"的真正价值不在存储隔离，而在治理语义：预备区 = 冻结的审核队列、来源透明以分区为执行单元、铁律豁免挂分区成员。
- 体感一致性（不同用户不同时间看到的库状态趋同）由高阻尼参数保障，不靠分区实现。
- 检索管线只读一个数，衰减是读时计算，协调任务只负责把跨界物化成审计事件。
