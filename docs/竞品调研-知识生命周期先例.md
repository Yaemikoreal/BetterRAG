# 竞品调研：知识生命周期/信任分级机制的商业与生态先例

BetterRAG 六机制编号（下文引用）：①三级信任分区（答案标注来源分区）②引用计分自动晋升 ③时间衰减降级+自动归档 ④晋升稳定区人工一道门 ⑤冲突仲裁 ⑥审计链。全部 URL 默认 https://，均经本轮实际抓取或搜索引擎索引双重核验；查不到的已明确标注，未编造任何功能。

## 逐项发现

**1. Guru 知识验证三件套**（最接近的商业先例）
URL: help.getguru.com/docs/verifying-and-unverifying-cards；help.getguru.com/docs/automating-card-management-autoarchive-duplicate-detection；getguru.com/features/automated-knowledge-quality
机制：(1) 人工验证：建卡指定验证人+验证间隔（30/60/90天/半年/1年/永不过期；2026年起新集合默认"永不过期"）；到期卡片标注过期（官方喻为 "freshness date"）进验证人队列——经典模式只标记不隐藏、不降权。(2) 自动归档：每周检查"未验证满6个月+零浏览"的卡片→入验证人待归档队列→一周无人处理即自动归档；可自定义规则（未验证35/60/180/365天 × 期间浏览0/<5/<10/<15次）；归档卡**不出现在搜索与AI建议答案**，可恢复、可区分自动/手动归档。(3) Automated Knowledge Quality（新功能）：AI 用使用信号（usage/views/feedback/expert interactions）+内容信号（时效性/新鲜度/相关性）持续自动验证/撤销验证，每次给理由+confidence level、全量日志供审计，人可随时否决；未验证内容可自动排除出答案与搜索。官方定位是"AI 提议、专家掌控"（"Automation proposes verification… experts retain full visibility and control to review, override"）。
重叠：(3)≈②③⑥，(2)≈③；另有官方 Agent 技能 "Find Stale And Conflicting Content"（help.getguru.com/docs/find-stale-and-conflicting-content，≈⑤的检测半步）。
没有：段落级连续置信度评分、引用计数→自动晋升冻结、答案级信任来源标注；冲突只检测不仲裁。
可借鉴：归档前给验证人一周缓冲窗；"编辑即恢复可信"降低重审负担。

## 核心问题回答

**Q1（Guru式"验证到期失权" vs BetterRAG"连续置信度+使用计分+时间衰减"）**：Guru 经典模式=二元信任+人工周期续期：时间只触发提醒、不改信任值，到期仅标过期+排队（不隐藏、不降权）；真正"失权"只发生在自动归档（未验证6个月+零浏览→排除出搜索/答案）与 2026 的 AI 自动验证/撤销两处。用使用信号驱动信任**已有先例**：Guru（views/feedback 进验证与归档决策）、Sierra（按引用频次排行）、Dify（标注命中分析）、unimatrix（注入率新鲜度）——但商业产品全部是"AI 提议、人决断"，无一家做到"引用计数跨阈值→自动晋升冻结"。差异不在信号（已被使用）而在**执行权**：BetterRAG 让信号自动执行晋升/降级，人只守一道门+抽查否决。

**Q2（新知识先上线后审核+答案标注信任来源）**：**查不到先例**。Sierra（"approved before publication"）、Intercom（人点按钮发布）、Guru、Coze 全部先审后发；答案级信任标注亦未发现（最接近=Guru 卡片级 trust indicator，不在答案级）。此二点是 BetterRAG 可主张的原始差异，但需实验验证"标注来源：学习区"不会摧毁用户信任。

**Q3（最接近完整生命周期者）**：**Guru** 最接近——人工验证+自动归档（时间×使用双条件）+AI 自动验证/撤销（置信度+审计日志）+冲突/陈旧检测技能，覆盖②③⑥大半、⑤半步；Sierra/Intercom 补上④的"缺口→起草→人工审"闭环。无人集齐：段落级连续置信度、显式引用积分晋升、答案信任标注、冲突仲裁阶梯（Bloomfire 仅检测+并排对比辅助人工裁决）。**风险提示**：unimatrix 实测纯时间半衰期衰减会在静默期误伤旧而有效的知识——BetterRAG"置信度×新鲜度"双因子方向正确，但必须验证"低频引用≠低价值"场景（如运营商基础资费），必要时参考"时间只作 TTL 门控、引用信号主导"做对照实验。
