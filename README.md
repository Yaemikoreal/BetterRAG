# BetterRAG

**自演进知识库 Agent**：第一个自己维护自己的知识库——信任由真实使用的结局供证，慢升快降，冲突当场仲裁，铁律自带修正程序。**越用越准，越用越干净。**

> 一句话内核：整个系统只有一个状态变量「置信度」，三级分区（学习区/预备区/稳定区）是它的区间投影，全生命周期是一连串带审计的置信度事件。新知识当天可用（诚实标注来源）；**被动结局供证**（采纳只保鲜不积分、沉默计零），**慢升**（举证期七天 + AI 挑刺自动转正），**快降**（负证据加衰减自动退场），冲突走仲裁阶梯与铁律红灯（挑战者挂起保全、修正案一键接替），归档不删除、审计链全程可回放。

**项目现状**：设计、调研、体验评估、13 天排期已全部闭环；代码 0%——只欠第一行 `clock.py`。

## 三、核心决策速览（五轮设计拷问的一页沉淀）

| 决策 | 内容 | 详见 |
|---|---|---|
| 唯一状态变量 | 置信度 [0,1]：决定分区、检索权重与生命周期；物理上无 zone 列，分区=读时投影 | ADR-0001 |
| 分区边界 | 学习区 [0.05, 0.60) · 预备区 [0.60, 0.75) · 稳定区 [0.75, 1.00]；晋升置入 0.85；常规事件上限 0.749，AUTO_PROMOTE 为唯一特权跨界事件 | 规格 §2 |
| 设计宪法 | 机制五问：一句话讲清 / 成本声明 / 坏了有退路 / 可测可演 / 差异清晰——五问全过才进核心 | 规格 §1 |
| 慢升快降 | 证据驱动（被动结局计分，沉默为零）＋ 举证期七天 ＋ AI 挑刺自动转正；降级全自动；人工只裁例外与红灯 | ADR-0005、规格 §4 |
| 高阻尼参数 | 正证据 +0.02 / 重问 −0.02 / 转人工 −0.03 / 踩 −0.04；半衰期 90/365 天；宽限 14 天；废弃线 0.05（≈232 天）；降级落点 0.70 | 规格 §7 |
| 保鲜与信任解耦 | 有效置信度 = 存量 × 新鲜度（闲置衰减，采纳重置）；棘轮：掉的分不返还；tenure：稳定区内攀升延长闲置容忍（80→165 天） | 规格 §2 |
| 仲裁阶梯 | 冲突计数 N=3 → 铁律位走红灯通道（挑战者挂起保全＋修正案一键接替）→ 差 ≥0.25 对冲判负 → 影子双答当场点选 | 规格 §8 |
| 铁律修正案 | 铁律记账零豁免：异议或负证据异常点亮红灯；一键接替为原子交接＋取代链 | 规格 §4.3 |
| 知识星图 | 全库知识块降维投影：分区着色、冲突连线、时间滑块回放代谢史——全部核心机制的视觉替身（demo 开场镜 1 / 收尾镜 9） | 规格 §13 |
| 照搬原则 | 知识块=原文切片，AI 只写归纳摘要标签，幻觉进不了库 | ADR-0003 |
| 两大维度 | 治理单元=知识块，召回单元=材料（分区不切断上下文）；+ 探索召回解曝光悖论 | ADR-0002、规格 §5 |
| 原创性定位 | 四件套（信号晋升+衰减降级+仲裁+人工门）调研未见集齐者；差异核心=执行权自动化与完整仲裁阶梯；骨架有先例（ARIADNE/Guru），话术已修正 | 同类方案调研 §4 |
